📖 คู่มือ Rover X1 Simulator

ฝึกเขียน Python ด้วย คำสั่งเดียวกับหุ่นจริง (Dobot dobot_quad SDK) ในสนาม 3 มิติ ก่อนนำไปใช้กับ Dobot Rover X1 ตัวจริง

เริ่มต้นสถานะเคลื่อนที่ทรงตัว ท่าพิเศษ & ไฟอ่านข้อมูลAuto-correctMap โจทย์ฝึกใช้กับหุ่นจริงข้อจำกัด

1. เริ่มต้น

เขียนโค้ดในแท็บ 🐍 Code แล้วกด ▶ Run (หรือ Ctrl+Enter) หุ่นจะทำตามทีละคำสั่ง บรรทัดที่กำลังทำงานจะมีไฮไลต์สีฟ้า และ Console จะแสดงคำสั่งที่กำลังทำ (▶ สีเขียว) คล้ายกับ SDK จริง

from dobot_quad import RobotClient

robot = RobotClient("192.168.5.2:50051")   # หุ่นจริง: LAN 192.168.5.2 / WiFi 192.168.1.6
robot.balance_stand()        # ยืนก่อนทุกครั้ง (หุ่นเริ่มต้นในท่าหมอบ)
robot.walk_forward(2.0)      # เดินหน้า 2 m
robot.rotate("left", 90)     # หมุนซ้าย 90°
robot.stand_down()           # หมอบ
  • ทุกโปรแกรมต้องมี from dobot_quad import ... และ robot = RobotClient(...) เหมือนหุ่นจริง — ถ้าลืม Auto-correct จะเติมให้
  • ระบบหลบสิ่งกีดขวางเปิดอยู่ในโปรแกรมจำลอง แต่บนหุ่นจริงให้สั่ง robot.set_obstacle_avoidance(True) เองเพื่อความแน่นอน
  • ค่าที่หุ่นจริงไม่รับ (เช่น rotate("lefft", 90), dance(duration=1)) จะ error เหมือนหุ่นจริง พร้อมคำแนะนำ 💡 ส่วนคำพิมพ์ผิด Auto-correct แก้ในโค้ดให้
  • หุ่นเริ่มต้นในสถานะ stand_down (หมอบ) ถ้าลืม balance_stand() ระบบจะสั่งให้และเตือน — แต่หุ่นจริงควรสั่งเองเสมอ
  • พิมพ์ robot. จะมีรายการคำสั่ง SDK ขึ้นมาพร้อมพารามิเตอร์ (หรือกด Ctrl+Space)
  • มีแต่คำสั่งของหุ่นจริง (Poka-yoke) — ไม่มีคำสั่งพิเศษที่ใช้ได้เฉพาะในโปรแกรมจำลอง โค้ดที่รันผ่านในนี้จึงใช้คำสั่งที่หุ่นจริงมีทั้งหมด
💡 ■ Stop หยุดโปรแกรมได้ทุกเมื่อ · ↺ Reset พาหุ่นกลับจุดเริ่ม · Sim speed 2×–8× ช่วยดูผลเร็วขึ้น · ช่อง SDK state มุมซ้ายบนบอกสถานะ, speed_ratio และ 🛡 หลบสิ่งกีดขวาง

ระบบพิกัด (ค่าที่ได้จาก get_state)

ในโปรแกรมจำลอง (0,0) คือมุมซ้ายล่างของสนาม · หุ่นจริงจะนับจากจุดที่เปิดเครื่อง

2. สถานะ (state) ของหุ่น

stand_down→ balance_stand() →balance_stand→ walk() / flying_trot() →walk ⇄ flying_trot→ stand_down() / ready()
balance_stand()ยืนทรงตัว — สั่งก่อนเดิน และต้องอยู่สถานะนี้ตอนใช้ balance_* / dynamic_pose
walk() / flying_trot() / rl()เปลี่ยนโหมดการเดิน (ยังไม่ออกเดิน) · change_mode() สลับเดิน ⇄ วิ่ง
stand_down() / ready()หมอบ / ค่อย ๆ หมอบอย่างปลอดภัย
passive() = emergency()ตัดไฟมอเตอร์ทันที (หุ่นจริงจะทรุดลง ใช้ตอนฉุกเฉิน)
set_target_state("walk")เปลี่ยนสถานะด้วยชื่อ
get_current_state_name()สถานะปัจจุบัน · ⚠ ยังไม่ทราบว่าหุ่นจริงคืนเป็นตัวเล็กหรือใหญ่ ถ้าจะเปรียบเทียบให้ใช้ .lower() เช่น robot.get_current_state_name().lower() == "walk"
enable_safety_ready()หุ่นจริง: กด Ctrl+C แล้วหมอบอย่างปลอดภัย (ในโปรแกรมนี้ใช้ปุ่ม Stop)

3. เคลื่อนที่

walk_forward(d) walk_backward(d)
move_left(d) move_right(d)		เดินเส้นตรง d เมตร · 0–3 m ต่อคำสั่ง (เกินจะถูกตัดเหลือ 3) · ใส่ speed_ratio= ชั่วคราวได้
line_walk(direction, distance)direction = 0 หน้า, 1 หลัง, 2 ซ้าย, 3 ขวา (หรือ "forward", "back", ...)
rotate("left"/"right", angle)
rotate_left(a) rotate_right(a)		หมุนอยู่กับที่ 0–3600°
circle("left", turns)หมุนครบรอบ 1–10 รอบ
rotate_walk(angle, distance)หมุนไปทิศ angle แล้วเดิน · บวก = ขวา, ลบ = ซ้าย (−180..180)
velocity_sequence(steps, gait="walk")steps = [(vx, vy, vyaw, วินาที), ...] · vx/vy m/s, vyaw rad/s (บวก = หมุนซ้าย) · gait "walk"/"flying_trot" · ค่าเริ่มต้น stand_down_after=True หมอบเมื่อจบ
set_speed_ratio(10–100)ความเร็วพื้นฐาน (%) · อ่านค่าด้วย get_speed_ratio()
set_obstacle_avoidance(True/False)🛡 หลบสิ่งกีดขวาง (เปิดอยู่แล้วตั้งแต่สร้าง RobotClient)

ทุกคำสั่งเดินคืนผลลัพธ์ที่มี .success — ถ้าหุ่นหยุดก่อนถึงระยะ (เจอสิ่งกีดขวาง) จะได้ False

from dobot_quad import RobotClient
robot = RobotClient("192.168.5.2:50051")
robot.balance_stand()
robot.set_speed_ratio(70)
for i in range(4):                 # เดินเป็นสี่เหลี่ยม 2x2 m
    robot.walk_forward(2.0)
    robot.rotate_left(90)
steps = [(0.6, 0, 0.5, 4), (0, 0, 0, 1)]   # เดินโค้งซ้าย 4 วินาที แล้วหยุด
robot.velocity_sequence(steps, gait="walk", stand_down_after=True)

4. ทรงตัว / ท่าทาง (ต้องอยู่ใน balance_stand)

balance_pitch(v, duration, mode)ก้ม/เงย ±11.5° (บวก = ก้มหน้า)
balance_roll(v, duration, mode)เอียง ±17° (บวก = เอียงซ้าย)
balance_yaw(v, duration, mode)หันตัว ±11.5° (บวก = หันขวา)
balance_height(v, duration, mode)ย่อตัว −0.08 ถึง 0 m
dynamic_pose(duration, roll_deg, pitch_deg, yaw_deg, height_m)
static_pose(...)		หลายแกนพร้อมกัน (ค่า 0 = ไม่เปลี่ยน) · duration 1–5 s
balance_sequence([...])หลายท่าต่อกัน [("balance_pitch", 10, 2.0, "dynamic"), ...]
balance_neutral()กลับท่าตรง

mode "dynamic" = ค่อย ๆ ไปถึงแล้วค้างไว้ · "static" = ไป–ค้าง–กลับท่าเดิม · duration 0.5–5 s

from dobot_quad import RobotClient
robot = RobotClient("192.168.5.2:50051")
robot.balance_stand()
robot.balance_pitch(10, 2.0, "dynamic")
robot.balance_roll(-15, 2.0, "static")
robot.dynamic_pose(3.0, roll_deg=10, yaw_deg=-10, height_m=-0.05)
robot.balance_neutral()

5. ท่าพิเศษ & ไฟที่ขา

wave_hand(duration) jump() backflip() dance(duration=…) gongxi() recovery()
ท่าเต้นสั้น: twirl_jump() diag_step() hop_step() groove() bounce() body_wave() hip_circle() head_circle() (จบแล้วกลับเป็นสถานะ walk)

⚠ dance() ค่าเริ่มต้นยาว 126.5 วินาทีเหมือนหุ่นจริง ใส่ dance(duration=10) ให้สั้นลง (4–128)

set_all_legs_color(Color.GREEN)ไฟทั้ง 4 ขา · สี: OFF RED ORANGE YELLOW GREEN CYAN BLUE PURPLE WHITE
set_leg_color(Leg.FL, Color.BLUE)ขาเดียว · ขา: FL FR RL RR (หน้าซ้าย หน้าขวา หลังซ้าย หลังขวา)
set_legs_rgb([LegLedConfig(Leg.FL, 0, 0, 255), ...])หลายขาในคำสั่งเดียว ต้องใช้ LegLedConfig · ⚠ แบบในเอกสาร set_legs_rgb([Leg.FL], Color.BLUE) ใช้กับหุ่นจริงไม่ได้ (error)
set_leg_rgb(Leg.RR, 255, 0, 128)ขาเดียว ค่า RGB 0–255 (เกินช่วง = ValueError เหมือนหุ่นจริง) · สีต้องเป็น Color.X ไม่ใช่ข้อความ "green"
set_leg_brightness(Leg.FL, 128)ความสว่าง 0–255
reset_legs()คืนไฟให้หุ่นควบคุมเอง
from dobot_quad import RobotClient, Leg, Color
robot = RobotClient()
robot.balance_stand()
robot.set_all_legs_color(Color.PURPLE)
robot.set_leg_color(Leg.FL, Color.YELLOW)
robot.set_leg_color(Leg.FR, Color.YELLOW)
robot.jump()
robot.twirl_jump()
robot.reset_legs()

8. วาด Map 3 มิติ

แท็บ 🗺 Map → เลือกเครื่องมือ → คลิกบนพื้น (ลากเมาส์ = หมุนกล้อง, ล้อ = ซูม, คลิกขวาลาก = เลื่อน) · Shift ค้าง + ลาก = วาดต่อเนื่อง

🪜 Stepสูง ≤ 0.15 m จากพื้นที่ยืนอยู่ หุ่นเดินขึ้นได้ (ต่อหลายขั้นเป็นบันได) · ก้าวลงได้ไม่เกิน 0.25 m ถ้าสูงกว่านั้นหุ่นจะหยุดที่ขอบ

9. โจทย์ฝึก (ใช้คำสั่งจริงอย่างเดียว)

  1. สี่เหลี่ยม — เดินสี่เหลี่ยม 2×2 m กลับมาจุดเดิม แล้วเช็กตำแหน่งด้วย get_state()
  2. ดาว 5 แฉก — for + walk_forward + rotate_right(144)
  3. เดินโค้ง — ใช้ velocity_sequence วาดรูปเลข 8
  4. เดินไกลกว่า 3 m — เขียนฟังก์ชัน walk_far(d) ที่แบ่งเป็นช่วงละไม่เกิน 3 m
  5. เก็บธง — เขียน go_to(x, y) เองจาก pos_body + ori_body (ดูตัวอย่างที่ 4 ในเมนู 📂 Examples)
  6. หยุดก่อนชน — เดินไปทางกำแพง ใช้ .success ตรวจว่าหุ่นหยุดเพราะเจอสิ่งกีดขวาง แล้วเปลี่ยนไฟขาเป็นสีแดง
  7. โชว์ — ทำชุดท่าทรงตัว + ไฟ + ท่าเต้น ยาว 30 วินาที
# เฉลยข้อ 2: ดาว 5 แฉก
from dobot_quad import RobotClient, Color
robot = RobotClient()
robot.balance_stand()
robot.move_left(1.5)                 # ออกห่างขอบสนามก่อน ดาวต้องใช้พื้นที่
robot.set_all_legs_color(Color.YELLOW)
for i in range(5):
    robot.walk_forward(2.0)
    robot.rotate_right(144)
robot.stand_down()

10. นำโค้ดไปใช้กับหุ่นจริง

  1. ใช้คอมพิวเตอร์ Ubuntu 22.04 + Python 3.10 ขึ้นไป (ตาม README ของ SDK) — บน Windows อาจต้องใช้ WSL2
  2. git clone https://github.com/Dobot-Team/dobot_quad_sdk → cd high_level/python → pip install .
  3. ต่อเครือข่าย: สาย LAN → 192.168.5.2 (ตั้งเครื่องเราเป็น 192.168.5.xxx) หรือ WiFi ของหุ่น Rover-* → 192.168.1.6 แล้วแก้ IP ใน RobotClient(...)
  4. คัดลอกโค้ดจากโปรแกรมจำลองไปเป็นไฟล์ my_program.py แล้วรัน python3 my_program.py (ต้องมีบรรทัด from dobot_quad import RobotClient และ robot = RobotClient("IP:50051"))
  5. ครั้งแรกทดสอบในที่โล่ง ใช้ set_speed_ratio(30) และ robot.enable_safety_ready()

อ้างอิง: Dobot-Team/dobot_quad_sdk → docs/docs/api/high_level.md

11. ข้อจำกัดของโปรแกรมจำลอง

⚠ เป็นตัวจำลองเพื่อฝึกเขียนโปรแกรม ไม่ได้มาจาก Dobot โดยตรง

  • robot.* ใช้ ชื่อคำสั่ง/พารามิเตอร์/ช่วงค่า ตามเอกสาร SDK แต่ผลที่ได้เป็นการประมาณ — ความเร็วที่ speed_ratio 100 ตั้งไว้ เดิน 1.0 m/s, วิ่ง 1.8 m/s (ไม่มีในเอกสาร ปรับได้ที่ MODE_SPEED ใน sdk_compat.py)
  • ไม่มีฟิสิกส์จริง (แรง การลื่น การล้ม) ท่าเต้น/กระโดด/ตีลังกาเป็นแค่ภาพเคลื่อนไหว
  • ระบบหลบสิ่งกีดขวางในนี้หยุดหุ่นเมื่อเข้าใกล้ ~12 cm — ของจริงอาจทำงานต่างไป
  • Low-level SDK (DDS: มอเตอร์รายข้อ, IMU ดิบ, กล้อง RGB/Depth, แบตเตอรี่) และ robot.video ยังไม่ได้จำลอง — จึงไม่มีเซนเซอร์วัดระยะให้ใช้ ใช้ระบบหลบสิ่งกีดขวาง + .success แทน (ดูตัวอย่างที่ 5)
  • ในโปรแกรมจำลองมีตัวแปร robot สร้างไว้ให้แล้ว แต่บนหุ่นจริงต้องเขียน robot = RobotClient("IP:50051") เอง
  • หุ่นแบบล้อ (miniQuadW: wheel_loco, drift, handstand) ไม่รองรับ — Rover X1 ในนี้เป็นแบบขา
